# Mace and Clubs v0.15.0: gyroscope-primary mace counting

Mace swing counting now follows wrist rotation instead of acceleration spikes.
The Instinct 3 Solar 45 mm supplies a 25 Hz gyroscope stream; the app smooths
its three-axis rotation magnitude, confirms local peaks causally, and enforces
a one-second refractory interval so one broad overhead pass counts once.

The shared detector was selected across two independently labelled real mace
recordings. Offline replay reproduces every work set: `[5, 5, 10, 10]` in the
short recording and `[60, 60]` in the workout that the accelerometer counter
seriously undercounted. Acceleration spikes no longer drive mace counts.

## Supported watch

This release intentionally supports only the Instinct 3 Solar 45 mm. It is the
one physical watch for which the app has labelled recordings, a verified 25 Hz
gyroscope profile, and successful production and test builds. Commented SDK
profiles remain research candidates rather than advertised compatibility.

Club and bulava workouts retain their existing acceleration-based counting
path; the gyro-primary change applies to mace movements where labelled data is
available.

## Analysis and validation

- Raw per-axis gyroscope export for private offline analysis
- A causal detector shared between the watch implementation and replay tests
- Labelled FIT fixtures covering short sets and the 60/60 workout
- A tuning script that scores detector settings across all labelled fixtures
- Garmin simulator unit tests, production builds, FIT schema validation,
  CodeQL, lint, synthetic FIT checks, and function coverage in CI

Simulator validation confirms compilation, app flow, and deterministic sensor
tests; it cannot replace a fresh physical-watch workout for live wrist motion.
