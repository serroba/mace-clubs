# Mace and Clubs v0.10.1: a clearer workout summary

This patch makes the paused and completed workout summary fit the Instinct
display properly. The state heading now stays clear of the circular subwindow,
the selected set's work and rest durations are labelled, and the action hints
use a quieter extra-small treatment so the training numbers remain the focus.

The screen also replaces the unexplained `2H` abbreviation with `Both`, uses
the readable `smooth --` label when there is not enough motion for a score, and
hides a zero load-exposure value when the sensor recorded no active window.

## Included in this release

- Paused and completed headings no longer collide with the Instinct subwindow
- Clear `Both`, `W`, and `R` labels for side, work, and rest
- Correct singular `1 set` wording
- Readable `smooth --` unavailable state
- Zero motion exposure is no longer presented as a meaningful load value
- Smaller save, resume, navigation, and discard hints
