# Mace and Clubs v0.10.0: your history, on the watch

Smoothness scores used to vanish the moment you left the end-of-workout
summary. This release keeps them. The watch now stores a rolling log of your
last 20 sessions, browsable from **Settings > History**: each row is a date and
its session average, and opening one scrolls through the per-set scores with
UP/DOWN, the same way the post-workout screen does. The implement, quantity,
and weight are shown with each session, so a 6 kg bulava session is never
mistaken for a 10 kg mace one. Everything stays on the watch — nothing is
uploaded.

The idle screen picked up the other half of that: the last comparable session's
smoothness, with its trend, now sits at the bottom before you start. It only
appears once there is history for the implement, movement, and side you have
selected, so it stays blank rather than comparing work that isn't alike.

New in this release is **load exposure**, an optional per-set summary of wrist
motion. Turn it on from the watch or Garmin Connect and each work block records
its dynamic acceleration exposure, its peak, how many seconds were actually
active, and weight-volume (implement kilograms times detected swings). The set
browser shows it as a compact `L` token — `48sw S87 L12.4k` — and the full
values are written as FIT lap developer fields for offline analysis.

Read the interpretation notes before you draw conclusions from it:
[docs/load-exposure.md](../load-exposure.md) is explicit that these are
descriptive measurements from a wrist accelerometer, not tendon force, joint
torque, technique quality, or injury risk. They are for like-for-like review —
same implement, weight, movement, and working side — and the app deliberately
keeps them as separate transparent numbers rather than blending them into one
physiological-sounding score. It costs extra battery, so it is off by default.

## Included in this release

- Session history browser in Settings: last 20 sessions, newest first
- Per-set smoothness scroll for any saved session, labelled with its implement
- Last comparable session's smoothness and trend on the idle screen
- Optional exercise load exposure: motion exposure, peak, active seconds, and
  weight-volume per work set
- Compact `L` token in the paused and completed set browser
- Load fields written as FIT lap developer fields
- Load exposure toggle on the watch and in Garmin Connect (off by default)

## Under the hood

- Function coverage from the unit tests is uploaded to GitHub code coverage on
  every CI run
- `make coverage` now runs the whole instrument/compile/run/report pipeline
