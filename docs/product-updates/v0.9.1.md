# Mace and Clubs v0.9.1: know what you're running

A small release that answers one question at a glance: which version is on
your wrist. The settings menu now ends with an About row showing the app
version, and every release build verifies that the version it reports
matches its tag before it publishes.

## Included in this release

- Version row at the bottom of the on-watch settings menu
- Release pipeline refuses to build a tag that would misreport its version

Download the release from
[GitHub](https://github.com/serroba/mace-clubs/releases/tag/v0.9.1).
